# WikiPsilocybin design system

Visual layer only: `/assets/site.css` is loaded after each page's inline `<style>`, so it restyles every page without changing any content. Sources are numbered as in [sources.md](sources.md).

## 1. Principles
- **Reading first.** Decoration is limited to thin rules, one accent stripe and tinted panels. First impressions of credibility form in ~50 ms and are driven by visual quality and low clutter [S7, S8, S9].
- **One interactive colour.** Forest green is used only for things you can click (links, active tab, buttons). Links in prose stay underlined, so colour is never the only cue (WCAG 1.4.1) [S1, S11].
- **No colour-psychology claims.** Colours were chosen for contrast, legibility and tone, not for supposed emotional or conversion effects, which the research literature does not reliably support [S10].

## 3. Typography
| Role | Default (A) | Variant (B, `?type=sans`) |
|---|---|---|
| Body, H2, H3 | Source Serif 4 | Inter |
| H1 | Source Serif 4, 600, `clamp(32px…44px)` | Inter |
| UI (nav, tabs, tables, infobox, notices, references) | Inter | Inter |

- Body **18 px / 1.65** desktop, **17 px** under 720 px. Larger type and generous line spacing improved reading for web text [S5].
- Measure capped at **68ch** for prose (≈ 60–75 characters per line) [S6].
- Scale: H1 32–44 px → H2 26 px (23 px mobile) → H3 20 px (19 px mobile) → body 18 px → UI 15 px → meta 13–14 px.
- All sizes are in `rem`, so browser text scaling works (WCAG 1.4.4); no fixed heights clip text (1.4.12). Verified: no horizontal scroll at 390 px (1.4.10).
- Why A/B test rather than pick: font effects on reading speed vary by individual, with no universal best typeface [S12]. Both fonts are open-licensed (SIL OFL) [S13, S14].

## 4. Components

### Links
Underlined (1 px, 45 % opacity) → hover: 2 px solid underline + darker green. Visited: purple. Focus: 3 px charcoal outline, 3 px offset, ivory halo, so it is visible on both ivory and green (WCAG 2.4.7; meets 2.4.13 area/contrast intent) [S1].

### Buttons (`.btn-primary`, `.btn-secondary`)
- Primary: solid forest, white text (9.1:1). Secondary: outline, subordinate.
- Min height 44 px (exceeds WCAG 2.2 2.5.8 24 px minimum) [S1].
- Labels must state the action and destination, e.g. "Read the PIVOT trial summary", "See our editorial methodology", "Email the editor" — never "Learn more" (WCAG 2.4.4 Link Purpose) [S1]. No purchase or fake-urgency buttons.
- Not yet placed on pages: adding buttons would change content. See the CRO backlog for proposed placements.

### Navigation hierarchy
1. Header: site name → primary nav (Recent events, Overview, Research, Safety & risks, Addiction, Legal status, About).
2. Page tabs: Article / Recent events.
3. In-page: breadcrumb (event pages) → table of contents → section headings.
4. Footer: full link list incl. Editorial policy.

Change: the header nav was **hidden on phones**; it is now a horizontally scrollable row so mobile users keep access to the research hubs.

## 5. Templates
- **Homepage / article** (`/`, safety and addiction guides): header → tabs → H1 + subtitle → right-floated fact box (stacks above content < 860 px) → TOC → prose at 68ch → references.
- **Event** (`/events/*`): breadcrumb → H1 → date/tag band → "At a glance" box → summary → source box → back link.
